# 機車路口待轉預告系統 PRD 文件

## 1. 專案概述
- **背景與動機**：
  台灣與部分地區的道路設計中，機車在許多大型路口左轉時，必須實施「兩段式左轉」（即先直行至待轉區，待綠燈後再行駛）。然而，在行車過程中，騎士往往因道路標誌不明顯、車速過快，或對路況不熟，直到逼近路口才發現需要待轉。這常導致騎士在車流中緊急切換車道，或直接違規左轉，面臨嚴重的交通安全隱患及違規罰單。
  本系統旨在開發一個專為機車族設計的「路口待轉預告系統」，透過即時定位，在騎士抵達待轉路口前 30 到 50 公尺，以聲音與高對比視覺警示主動提醒是否需要待轉，並提供剩餘公尺倒數與夜間亮度自動調整功能，確保騎乘安全與行車秩序。
- **目標用戶**：機車通勤族、外送員、機車旅遊愛好者及不熟悉路況的騎士。
- **核心價值主張**：利用即時定位與人性化的視覺、語音雙重警示，加上精確的距離倒數與夜間護眼亮度調整，讓騎士免除低頭確認路況的危險，提早安全減速並流暢切換車道進入待轉區。

---

## 2. 功能需求

系統需提供以下 5 項核心功能：

1. **進入前 30 到 50 公尺待轉提醒**
   - **使用者故事**：作為一名機車騎士，我希望在即將抵達需要兩段式轉彎的路口前 30 到 50 公尺收到警示，以便我有足夠的時間與安全視距，順暢地往道路外側靠攏，避免臨近路口時緊急變換車道。

2. **語音提示功能**
   - **使用者故事**：作為一名行進中的騎士，我希望在需要待轉的路口前聽到清晰的語音警示（例如：「前方路口請待轉」），以便我無須在高速行駛下冒險低頭看螢幕也能得知路口規則。

3. **畫面高對比視覺警示**
   - **使用者故事**：作為一名將手機架在手把上的騎士，我希望需要待轉時螢幕有顯眼的視覺提示（如待轉圖標閃爍或高對比框線），以便我利用餘光就能立即感知警示狀態。

4. **環境偵測夜間模式自動降亮**
   - **使用者故事**：作為一名夜間騎乘的騎士，我希望系統能偵測環境光線或依時間段自動切換至夜間模式並調降螢幕亮度，以便在黑暗中避免螢幕強光直射雙眼，減輕眼睛疲勞並維持對前方路況的夜間視力。

5. **進入警示區後距離路口倒數公尺數顯示**
   - **使用者故事**：作為一名行駛於車流量極大路段的騎士，我希望在進入警示區（路口前 50 公尺起）後，畫面上能以大字體顯示距離路口的剩餘公尺數倒數（如：50m... 40m... 30m），以便我能精確掌握減速與切換至外側車道的最佳時機。

## 3. 非功能需求

- **技術限制**：
  - 系統需基於 Flask + Jinja2 + SQLite 技術堆疊進行開發。
- **效能考量**：
  - GPS 位置比對與剩餘公尺數的更新頻率需高於每秒一次（<= 1s），以確保在車速 50-60 km/h 下，倒數數據仍具即時性。
  - 警示觸發延遲應控制在 150 毫秒內。
- **安全考量**：
  - 語音提示需支援解鎖播放，音效警示音應清晰但不干擾騎士的注意力。
  - 螢幕亮度的自動調降應在偵測環境光線變化後 1 秒內反應。

---

## 4. MVP 範圍

### Must Have（必須有）
- **待轉判斷與 API 查詢**：判斷當前座標與前方路口的待轉規定，於路口前 50m 起回傳待轉指示。
- **畫面視覺警示**：超大字體視覺待轉標誌提醒。
- **倒數公尺數顯示**：即時更新呈現距離路口的剩餘公尺數。

### Should Have（應該有）
- **語音警示**：藉由 Web Speech API 語音合成技術播放「前方路口請兩段式轉彎」。
- **環境光線偵測降亮**：利用瀏覽器 Ambient Light Sensor API（或依日落時間回退）自動調降網頁背景亮度至夜間暗色模式。

### Nice to Have（可以有）
- **路口待轉語音客製化**：允許使用者自訂待轉語音音量，或切換為精簡警示音。
- **歷史路口註記**：讓騎士可以手動標記經常發生危險的無標示待轉路口。
