# Google Maps 地圖導航系統 - 產品需求文件 (PRD)

## 1. 專案概述

### 背景與動機
在現代繁忙的交通環境中，用路人（包含行人、機車族、汽車駕駛等）面臨著多變的路況、複雜的交通規則（如台灣特有的機車兩段式待轉）以及無所不在的測速照相。現有的主流地圖導航系統雖然功能強大，但往往缺乏針對特定用路人（如機車騎士）的貼心安全預告功能，且個人化路徑的客製化程度有限。

本專案旨在打造一個整合「導航」、「路口待轉預告」、「即時測速監測」與「個人化路徑偏好」的智慧地圖導航系統，協助所有用路人更安全、流暢且無壓力地抵達目的地。

### 目標用戶
- **所有用路人**：包含機車騎士、汽車駕駛與通勤族。
- **機車族/外送員**：需要特別注意路口待轉規則與即時速度控制的族群。
- **通勤與旅遊者**：偏好自訂特定駕駛路線（避開塞車、避開高架橋或偏好大路）的用戶。

### 核心價值主張
結合即時路況、法規警示（待轉預告、測速監報）與高靈活度的個人化偏好，提供最貼近台灣及在地用路人需求的「安全第一」導航體驗。

## 2. 功能需求

系統核心包含以下 5 項主要功能：

### 2.1. 基礎與進階導航 (Navigation)
- **功能描述**：提供精確的起終點搜尋、最佳路徑規劃，並於地圖上以直觀的視覺與語音指引使用者前行。
- **使用者故事**：作為**用路人**，我希望在輸入目的地後系統能提供清晰的路線指引與即時轉彎導引，以便我能安全、不迷路地順利抵達目的地。

### 2.2. 路口待轉預告 (Intersection Two-stage Turn Alert)
- **功能描述**：在導航路線中，若前方路口有機車兩段式左轉（待轉）規定，系統應提前於畫面與語音進行雙重預告。
- **使用者故事**：作為**機車騎士**，我希望在接近需要兩段式左轉的路口前收到提前預告與警示，以便我有足夠的時間切換到外側慢車道並安全駛入待轉區。

### 2.3. 即時測速監測 (Real-time Speed Camera Monitoring)
- **功能描述**：在地圖與導航畫面上即時顯示當前行駛路段之速限，並在接近固定式或移動式測速照相點時，發出視覺與語音警報。
- **使用者故事**：作為**汽車或機車駕駛**，我希望在行駛中隨時看到當前路段的速限以及前方測速照相機的提醒，以便我能即時調整車速，確保行車安全並避免違規受罰。

### 2.4. 整合個人化路徑 (Integrated Personalized Route)
- **功能描述**：允許使用者自由設定路徑偏好（如避開特定擁擠路段、避開收費路段、避開高架橋、偏好路幅較寬的大路等），系統據此計算出最適合該用戶的專屬路線。
- **使用者故事**：作為**有特定偏好的駕駛者**，我希望系統能根據我的個人設定推薦客製化路線，以便我能享受符合我特定需求（如新手偏好大路、老人家避開複雜高架）的舒適駕駛體驗。

### 2.5. 即時路況與障礙物警示 (Real-time Traffic & Hazard Alerts)
- **功能描述**：串接即時路況資料，並允許用路人主動回報或接收路段施工、交通事故、路障等即時警示，並提供動態自動重新規劃路線（Re-routing）功能。
- **使用者故事**：作為**通勤族**，我希望在路上遇到事故、塞車或施工時能收到即時警示並自動重新規劃路線，以便避開擁塞路段並縮短通勤時間。

## 3. 非功能需求

### 技術限制
- **技術架構**：本系統應基於 **Flask + Jinja2 + SQLite** 技術堆疊進行開發，以確保系統架構輕量、易於部署且利於敏捷迭代。

### 效能考量
- **響應時間**：地圖圖資載入與路徑規劃計算必須在 **3 秒內** 完成，確保用路人在行進間不會因等待讀取而產生焦慮或迷路風險。
- **即時更新**：測速照相與路口警示的定位偵測延遲需控制在 **500 毫秒 (ms)** 以內，以達到即時警報的效果。

### 安全考量
- **個人隱私**：使用者的個人化路徑偏好與歷史行程記錄必須經過加密儲存（如 SQLite 中的敏感欄位加密），嚴防資料外洩。
- **行車安全機制**：導航介面字體與按鈕需足夠醒目，並具備自動亮度（日夜間模式）調整，降低駕駛分心的機率。

## 4. MVP 範圍

為了快速驗證產品核心價值，將功能劃分為三個層級進行開發：

| 層級 | 功能項目 | 具體描述 |
| :--- | :--- | :--- |
| **Must Have (必須有)** | 1. 基礎地圖與搜尋<br>2. 基礎路徑規劃與導航<br>3. 待轉路口標示與預告機制 | - 支援地圖起終點定位與導航<br>- 計算並呈現最佳路徑<br>- 顯示前方路口是否需要待轉 |
| **Should Have (應該有)**| 1. 即時測速照相警示<br>2. 個人化路徑偏好設定<br>3. 簡潔直觀的操作介面 | - 當前行車速限顯示與超速/測速照相警報<br>- 提供「避開高架」、「偏好大路」等基本過濾選項 |
| **Nice to Have (可以有)**| 1. 語音導航播報與提示<br>2. 即時路況回報與自動避堵 | - 提供語音播報功能<br>- 串接第三方即時交通流量資訊與社群回報機制 |
