# 機車安全速限警示與預告系統 PRD 文件

## 1. 專案概述
- **背景與動機**：
  現有導航軟體（如 Google Maps）雖然提供了路線規劃與部分路段速限顯示，但對於機車族（騎士）而言，在騎乘過程中頻繁轉頭或低頭查看手機導航畫面是非常危險的。此外，不同路段的速限變化往往缺乏提前預告，導致騎士在不知情的情況下超速，面臨交通安全隱患及違規罰單的風險。因此，打造一個專為機車族設計的速限警示與預告系統，提供直覺的視覺（螢幕變紅）與聽覺（警示聲）反饋，並提前預告前方速限變化，能顯著提升行車安全性與便利性。
- **目標用戶**：機車通勤族、外送員、機車旅遊愛好者。
- **核心價值主張**：透過即時的色彩與聲音雙重警示，加上前方速限預告，讓機車騎士在騎乘過程中無須分心盯著螢幕，即可輕鬆掌握速限狀態，提升安全並避免違規。

---

## 2. 功能需求
系統需提供以下 5 項核心功能：

1. **整合當前道路限速**
   - **使用者故事**：作為一名機車騎士，我希望系統能將我目前行駛道路的法定速限整合並顯示在導航畫面上，以便我能隨時比對當前車速，確保符合速限規定。

2. **接近或超過速限時發出視覺/聽覺警示**
   - **使用者故事**：作為一名每日通勤的騎士，我希望在我的車速接近速限（如達到速限的 95%）或超過速限時，系統能自動觸發警示，以便我立刻放慢速度。

3. **超速時發出警告聲**
   - **使用者故事**：作為一名必須專注於前方路況的騎士，我希望在超速時系統能透過耳機或手機喇叭發出警示聲響，以便我無須低頭看螢幕也能得知超速。

4. **超速時螢幕顯示變紅色**
   - **使用者故事**：作為一名將手機架在車架上的外送員，我希望超速時螢幕背景或速限圖示能瞬間變成紅色，以便我利用餘光就能立即注意到超速狀態。

5. **預告前方路段限速變化**
   - **使用者故事**：作為一名行經陌生山路或路段的騎士，我希望系統能在前方路段速限即將變低時（例如 300 公尺前）發出預告，以便我能提早收油門減速，平穩應對速限改變。

---

## 3. 非功能需求
- **技術限制**：
  - 系統需基於 Flask + Jinja2 + SQLite 技術堆疊進行開發。
- **效能考量**：
  - 速限警示（包含螢幕變色與聲音播放）的反應延遲必須低於 200 毫秒，以確保騎士能即時減速。
  - 前方路段速限預告的判斷應配合即時 GPS 座標更新，每秒至少進行一次比對。
- **安全考量**：
  - 警示設計必須符合安全防呆原則，警示聲響不可過於刺耳或干擾行車注意。
  - 使用者位置與車速等敏感隱私資訊需安全處理，不進行非必要的長期留存。

---

## 4. MVP 範圍

### Must Have（必須有）
- **道路速限整合**：載入道路速限數據，並隨位置即時更新。
- **超速警告聲**：當車速超過速限時，自動播放警告音效。
- **超速螢幕變紅**：當車速超過速限時，介面相關區塊或背景顯示紅色警示。

### Should Have（應該有）
- **接近速限警示**：車速接近速限時（如限速的 90% ~ 100% 之間）顯示黃色警示，提醒騎士注意。
- **前方速限預告**：即將進入速限降低路段前 300 公尺，在畫面上顯示預告圖示。

### Nice to Have（可以有）
- **客製化速限門檻**：允許使用者自訂觸發警示的速限容許值（例如：限速 +5 km/h 才警示）。
- **速限語音播報**：在速限降低時，用語音說出「前方速限降至 40 公里」。
